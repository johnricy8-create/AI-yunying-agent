# 库存与数据质量核查手册

> 阶段二示例知识库，需业务方审核后替换为真实 SOP。阶段一库存只展示与校验，不参与异常判定。

## 库存核查

1. 库存为 0：确认是否真实缺货、是否影响下单、是否需要补货或临时下架。
2. 库存过高：结合基线订单估算可售天数，评估促销、组合销售或采购节奏。
3. 库存为负：属于数据错误，先核对源数据，不要直接用于运营决策。
4. 库存与订单冲突：订单量大于浏览量、退款大于销售额、负值等都属于数据质量问题。

## 数据质量优先级

1. 必填字段缺失、类型错误、负值：该行隔离，不参与指标。
2. 商品 + 日期重复：保留最后一条，其余标记错误。
3. 未来日期：隔离并核对数据源。
4. 商品简介、店铺、平台、类目缺失：保留并提示，报告中标注“未填写”。

## 可执行动作

- 先修复数据质量问题，再解读异常。
- 库存为 0 的高浏览商品，优先确认补货与可售状态。
- 库存积压商品，评估促销或组合销售；涉及价格与预算需人工确认。
- 数据质量问题较多时，暂缓自动化建议，先核对源数据。

## 证据要求

- 引用库存、浏览量、订单量、数据质量摘要。
- 明确哪些行被隔离、哪些是警告。
- 不要把库存为 0 直接等同于“断货”，需确认是否仍在售。

## 风险提示

库存快照可能与实际可售库存存在延迟；涉及补货、下架、促销的决策必须人工确认。
